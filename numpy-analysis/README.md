# NumPy Data Analysis Project

# Overview
This project demonstrates data analysis using **NumPy** to perform high-performance numerical operations on a structured dataset. The focus is on leveraging vectorized operations to replace slow loops and handle data efficiently.

# Dataset
- **File:** `train.csv`
- **Rows:** 1460
- **Description:** A sample dataset containing numerical and categorical features used to practice data manipulation and statistical inference.

# Tools Used
- **Python:** The core programming language.
- **NumPy:** Used for multi-dimensional array processing and mathematical functions.

# Key Analysis
* **Array Filtering:** Using boolean indexing to extract specific data subsets based on complex conditions.
* **Statistical Calculations:** Computing mean, median, standard deviation, and variance to summarize the data.
* **Data Slicing:** Efficiently accessing specific rows and columns for targeted analysis.
* **Broadcasting:** Applying arithmetic operations across arrays of different shapes.

# Key Learnings
* **Efficient Array Operations:** Moving away from Python lists to NumPy arrays for faster computation.
* **Vectorized Computation:** Understanding how NumPy performs operations on entire arrays at once, significantly reducing execution time.
* **Memory Management:** Learning how NumPy handles data storage more compactly than standard Python structures.
